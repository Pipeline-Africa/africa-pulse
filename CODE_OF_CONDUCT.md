# Code of Conduct

## Our commitment

Africa Pulse is a community project. We want contributors to be able to participate in a respectful, constructive, and technically rigorous environment.

## Expected behaviour

Contributors should:

- Be respectful and professional.
- Critique ideas and implementations, not people.
- Assume good faith while remaining precise about technical disagreements.
- Welcome contributors with different levels of experience.
- Give actionable feedback.
- Respect project maintainers, reviewers, and contributors.

## Unacceptable behaviour

The following is not acceptable:

- Harassment or discrimination
- Personal attacks
- Threats
- Trolling or deliberate disruption
- Publishing private information without permission
- Other conduct that would make participation unsafe or hostile

## Enforcement

Project maintainers may remove, edit, or reject contributions and may temporarily or permanently restrict participation when behaviour violates this Code of Conduct.

For serious concerns, contact the project maintainers privately.

This Code of Conduct is intended to establish community expectations and does not replace applicable law or GitHub policies.
