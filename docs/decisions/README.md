# Architecture Decision Records

Significant decisions are recorded here as numbered ADRs (`NNNN-short-title.md`), so future contributors can understand why the system looks the way it does.

Each ADR should cover:

- Context
- Decision
- Alternatives considered
- Consequences
- Status (proposed, accepted, superseded, deprecated)
